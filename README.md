# Planko — Система визуализации и расчета раскладки отделочных материалов

Десктопное приложение (Windows `.exe` / Web CAD) для 2D-моделирования стен, проемов (двери, окна, ТВ-зоны), откосов, параметрической раскладки панелей и реек, интерактивного управления профилями/швами, а также формирования карт раскроя и спецификаций для цеха и монтажников.

---

## 📌 Основные параметры и материалы

### 1. Материалы (базовые типы)
* **Листовые панели:** `1220 × 2800 × 5 мм` (текстура/волокна ориентированы вдоль 2800 мм).
* **Реечные панели (тип 1):** `145 × 16 × 3000 мм` (шаг ламелей 145 мм).
* **Реечные панели (тип 2):** `145 × 15 × 3000 мм`.
* **Пустое пространство (`ПУСТО / VOID`):** зоны под зеркала, ниши, открытую покраску.

### 2. Профили и стыки (длина хлыста 3000 мм)
* **Шов по умолчанию:** ширина **`8 мм`** (стандартный зазор между панелями).
* **Стык в стык:** **`0 мм`** (плотное прилегание плит).
* **Тонкий профиль:** **`5 мм`**.
* **Широкий профиль:** **`10 мм`**.
* **Светодиодный LED-профиль:** **`10 мм LED`** (под монтаж ленты с мягким неоновым свечением на чертеже).
* **Периметр стены:** раздельная настройка левого, правого, верхнего (потолок) и нижнего (пол/плинтус) краев.

### 3. Хранение данных
* Локальная база данных **SQLite** (полная автономность, Offline-first, без внешних серверов).

## 🛠 Реализованный функционал и возможности системы

### 1. Интерактивный 2D CAD Холст (Konva + React)
* **Цельные монолитные плиты:** проемы дверей и окон отображаются аккуратными вырезами поверх плит без искусственного дробления панелей на микро-прямоугольники.
* **Умные размерные цепочки:**
  * Габаритные размеры стены (общая ширина и высота).
  * Поколоночные размеры по горизонтали и межуровневые высоты по вертикали.
  * Четкие выносные размеры дверных и оконных проемов.
* **Прецизионный Hit-Testing:** надежный выбор швов и панелей с первого клика с адаптивной областью захвата под любой масштаб зума.
* **Мульти-выбор через `Shift`:** выбор нескольких панелей или швов для массового редактирования или объединения.

### 2. Умное объединение блоков и упаковка в листы
* **Автоматическая упаковка в максимальный размер листа ($1220\text{ мм}$):**
  * При объединении смежных блоков одного материала движок суммирует их габариты и упаковывает в максимальные цельные листы по $1220\text{ мм}$ (со швами $8\text{ мм}$) + один остаточный лист в конце.
  * *Пример:* объединение $800 + 800 + 800\text{ мм}$ ($2424\text{ мм}$) $\rightarrow$ формирует Лист 1: $1220\text{ мм}$ + Лист 2: $1196\text{ мм}$ (вместо 3 панелей стало 2).
  * *Пример:* объединение $500 + 500\text{ мм}$ ($1008\text{ мм} \le 1220\text{ мм}$) $\rightarrow$ формирует ровно 1 монолитную панель $1008\text{ мм}$.
* **Объединение зон «ПУСТО»:** не имеет физических ограничений листа и объединяется в единый непрерывный блок.

### 3. Соединение продолговатых швов в единую линию
* **Сквозные линии профилей:** возможность выделить через `Shift` коллинеарные швы одной высоты/линии и соединить их в единый сквозной трек (например, LED-линия через всю стену).
* **Сквозная подсветка и управление:** клик по объединенной линии подсвечивает её целиком от края до края и открывает единый инспектор свойств.
* **Умный обход проемов:** швы, идущие по верхней кромке дверей ($Y = 2100\text{ мм}$) или боковым стойкам, не удаляются вырезами, а сшиваются с соседними швами стены в одну непрерывную линию.

### 4. Проемы и накладной декор
* **Двери (`DOOR`), Окна (`WINDOW`), ТВ-зоны (`TV_ZONE`), Ниши (`NICHE`).**
* Интерактивное перемещение (Drag & Drop) с точной привязкой координат в миллиметрах.
* Переключатель режима выреза (`isCutout`): физический вырез в плитах или накладной элемент поверх облицовки.

### 5. Сквозная производственная маркировка
* Автоматическая маркировка панелей вида `[Лист].[Деталь]` (например, `1.1`, `1.2.1`, `ПУСТО`), связывающая монтажный эскиз с картой раскроя цеха.

## 🏛 Архитектура проекта

```
┌────────────────────────────────────────────────────────────────────────┐
│ 1. Presentation Layer (React 18 + Mantine UI + Konva 2D CAD Canvas)    │
│    - Canvas: монолитные панели, интерактивные швы, размерные линии     │
│    - Sidebars: дерево стен и проемов, инспектор свойств, валидатор швов│
├────────────────────────────────────────────────────────────────────────┤
│ 2. Application Layer (Zustand Stores + Command Pattern)                │
│    - useProjectStore: управление состоянием, объединение, валидация     │
│    - ProjectState: селекторы ячеек, мульти-выбор швов, параметры стен  │
├────────────────────────────────────────────────────────────────────────┤
│ 3. Domain Layer (Pure TypeScript / Математический движок)              │
│    - LayoutEngine: расчет сетки, упаковка листов, слияние швов         │
│    - Geometry & Intervals: 1D интервалы, клиппинг проемов              │
├────────────────────────────────────────────────────────────────────────┤
│ 4. Persistence Layer (SQLite + Repository Pattern)                     │
│    - Автономное локальное хранение проектов, стен, материалов и швов   │
└────────────────────────────────────────────────────────────────────────┘
```

Подробное описание архитектурных решений и схемы БД см. в [ARCHITECTURE.md](ARCHITECTURE.md).
