# Фотографии шести декоров

Подключены WOOD:5007, WOOD:5189, FABRIC:7112, STONE:8016-3,
MIRROR:8812-15 и MIRROR:2223-30. Категория входит в ключ: одинаковый
артикул другой серии не получает чужую фотографию.

Оригинальные крупные планы скопированы без ретуши в public/textures/warehouse.
Происхождение каждого файла записано в sources.json. Файлы входят в сборку,
доступ к папке Downloads и интернету для них не нужен. Исходники занимают
около 56 МБ; при запуске они последовательно декодируются в холсты с длинной
стороной не более 2048 пикселей. При ошибке загрузки остаётся процедурная фактура.

Фото используются в образцах каталога, текстурном режиме 2D и 3D,
а также при отрисовке плоских панелей в 3D-альбоме PDF.
Технические чертежи и карты раскроя остаются без фото.

Это первый этап: образцы внешнего вида, а не сканы целого заводского листа.
Изображение подгоняется под отображаемую грань; на отдельных сегментах сложной
геометрии может повторяться. Реальный масштаб фактуры, общие координаты рисунка
между деталями, откосами и сгибами, ограничения раскроя по волокнам и отдельный
редактор текстур пока не реализованы.

Проверка: npm run build, npm test (9 тестов); в браузере проверены загрузка
всех шести фото в каталоге и отображение 5007 на стене в 2D и 3D.
PDF визуально не проверялся.
