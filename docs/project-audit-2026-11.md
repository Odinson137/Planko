# Проверка Planko: 10 ноября 2026

Проверены переписка заказчика, текущие исходники, патч
`Planko-macOS-29c8d1f.patch` из загрузок, локальный каталог профилей и
старый PDF «Окна Виктория». Патч применён отдельным коммитом с сохранением автора.

## Исправления

- Рабочая позиция MC-01 заменена на MC-04: длина хлыста 3000 мм,
  назначение — торцевой/стартовый профиль. В списках один MC-04, он доступен
  в фильтре торцевых. Наименование и прежняя роль «разделительный» исправлены.
- Сохранённые `profileArticle: MC-01` переводятся в MC-04 при открытии,
  импорте и передаче проекта редактору. Учтены торцы полигональных панелей,
  старые колонки/сегменты/поддетали, стыки стены, обрамление проёмов и стыки
  откосов. Зазоры, цвета, геометрия и исходный объект не изменяются. Простое
  открытие не переписывает файл или запись в хранилище; сохранение и экспорт
  содержат обновлённые назначения. Расчёт понимает старый артикул даже без
  предварительной загрузки в редактор. Поддерживаются также кириллические МС.
- Контроль заказа: отрезки 3000, 1500 и 1500 мм с прежними и новыми
  обозначениями на разных стенах дают два хлыста MC-04 по 3000 мм.
  Отрезок 2800 мм больше не требует двух хлыстов.
- Фильтр типов профилей больше не удаляет назначенный профиль с торца панели
  или группы стыков. Выбранная модель остаётся видимой при просмотре другого
  типа. Фильтрация не создаёт действие истории и не меняет статус сохранения.
- Обрамление проёма с выбранным профилем и нулевым зазором отмечается как
  настроенное. В свойствах торцов и обрамления показывается длина хлыста.
- Сводная карточка PDF монтажникам больше не называет все хлысты «3м»:
  конкретная длина каждой позиции остаётся в таблице. Это важно для DL-09,
  который по каталогу имеет длину 2500 мм.

## Сверка исходных данных

В локальном PDF «каталог профили» на странице 7 отдельно указаны MC-01
2700 мм и MC-04 3000 мм. Причина замечания — назначение другого изделия,
а не универсальная ошибка округления. На странице 12 DL-09 имеет длину
2500 мм: эту позицию не переводили на 3000 мм.

Выборочно проверены действующие страницы AllWall: сплошные панели
[ткань](https://allwall.by/sploshnaya-bambukovaya-panel-tkan),
[камень](https://allwall.by/sploshnaya-bambukovaya-panel-kamen),
[зеркало](https://allwall.by/sploshnaya-bambukovaya-panel-zerkalo),
реечные [GW30](https://allwall.by/reechnaya-stenovaya-panel-gw30),
[GW90](https://allwall.by/reechnaya-stenovaya-panel-gw90),
[GW40](https://allwall.by/reechnaya-stenovaya-panel-gw40) и
[HQ глянцевый мрамор](https://allwall.by/hq-bambukovaya-panel-glyancevyj-mramor).
Размеры проверенных реек совпадают с приложением: соответственно
153×16×3000, 158×15×3000 и 130×9×3000 мм. Общий формат сплошных панелей
1220×2800 мм и толщины 5/8 мм совпадают с [сайтом](https://allwall.by/sploshnye).
Поэтому первоначальные 145 мм из переписки не подменяют размеры этих моделей;
пользовательский размер можно добавить через каталог. Полная сверка всех
декоров и производственных сечений не проводилась.

## Остальные замечания из переписки

| Замечание | Результат проверки |
|---|---|
| Металл 0,8 мм и видимая часть 3/7 мм | Параметры разделены; зазор задаётся независимо. Покрыто тестами профилей и зазоров. Толщина металла MC-04 в исходном каталоге не указана и не выдумывается. |
| Кастомные панели 1200×600 мм | Есть в редакторе каталога; формат учитывается в нарезке и раскрое. Проверено существующими тестами. |
| Порталы отдельно от дверей | Тип PORTAL, сохранение, импорт и три откоса реализованы; есть тесты. |
| Профили проёмов только на нужных сторонах | Обрамление настраивается по сторонам. Отдельный артикул при зазоре 0 учитывается в заказе. |
| Ctrl+C, Ctrl+V, Ctrl+Z | Буфер стен и история проекта реализованы, включая Cmd на macOS; покрыты тестами. |
| Более удобные углы | Есть редактор плана стен и изгибов, соответствующие геометрические тесты. Удобство рабочего процесса требует приёмки заказчиком. |
| Ошибка откосов «Окна Виктория» | В старом PDF видны откосы 3450 мм на листах 1220×2800 мм. Текущий раскрой отклоняет такие детали с номером и ошибкой о выходе за границы. Соответствующие регрессии проходят. Исходного проекта Victoria в загрузках не найдено; повторить весь его расчёт нельзя. |
| Свободно добавлять и двигать профили | Самостоятельного инструмента произвольных профилей пока нет. Есть разрезы по двум точкам с назначением профиля стыку и настройки торцов. Это оставшийся функциональный запрос. |

## Проверки и границы

После патча исходные 418 тестов проходили. Добавлены шесть регрессий:
каталог и алиасы, общий заказ MC-04, все места хранения артикула, загрузка
в store, сохранение/импорт и подпись смешанных длин в PDF.

Команды: `npm ci --registry=https://registry.npmjs.org`, `npm test`,
`npm run test:types`, `npm run build`, `npm audit --omit=dev`.
Все 424 теста, проверка типов и production-сборка прошли. Аудит production
зависимостей: 0 известных уязвимостей; установлена DOMPurify 3.4.17 из патча.
В локальной браузерной сборке проверены миграция MC-01, показ хлыста 3000 мм,
сохранение назначений при смене фильтра у панели и группы стыков. Статус
сохранения и история при этом не меняются, ошибок консоли нет. Контрольная
сводная страница PDF с MC-04 и DL-09 отрендерена и проверена визуально:
в строках указаны соответственно 1×3 м и 1×2,5 м, общая карточка — два хлыста.

Патч macOS добавляет DMG/ZIP и команды сборки, меню и production preview,
включает sandbox и стандартную web security. Проверка DMG, подписи и запуска
на Mac из `docs/macos.md` относится к автору патча; здесь работа выполнялась
на Windows и сборка на macOS повторно не запускалась. Windows-установщик и
новый релиз приложения в этой проверке не выпускаются.
