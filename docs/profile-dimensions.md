# Размеры соединительных профилей

У MC-06 / DL-17 и их вариантов `-7` толщина металла — 0,8 мм.
Видимая ширина — 3 или 7 мм. Эти размеры хранятся раздельно.

Монтажный зазор (`width` в конфигурации стыка/торца) влияет на геометрию
деталей. Он не равен толщине металла автоматически. При выборе профиля
используется `mountingGap` из каталога, если он задан, иначе — видимая ширина.
Это сохранённое расчётное допущение, а не подтверждённый размер ножки профиля.
Точный зазор можно изменить в инспекторе, сохранив артикул. После получения
сечения производителя нужно задать `mountingGap` для соответствующей модели.

Холст получает видимую ширину отдельно от зазора. Спецификация группирует
профили по артикулу, видимой ширине, толщине металла, длине хлыста и цвету.
В PDF отдельно указаны видимая ширина и металл; количество хлыстов считается
по длине выбранного изделия. Для невыбранного артикула толщина не выдумывается.

Нарезка по формату листа использует тип шва стены (новая стена: 3 мм),
возвращает созданные швы и назначает вариант MC-06 для типов 3/7 мм.
Теневые швы 8 мм и другие каталожные изделия сохраняют свои размеры.

При открытии старых проектов сохранённые монтажные зазоры и геометрия
автоматически не переписываются: старые 8 мм могут быть намеренной настройкой.
Метаданные выбранного профиля берутся из обновлённого каталога.

Проверки: `npm test` и `npm run build`.
