# Planko для macOS

## Установка

1. Откройте `Planko-1.0.0-universal.dmg`.
2. Перетащите `Planko.app` на значок **Applications**.
3. Запустите Planko из Applications или Spotlight.

Один универсальный пакет содержит версии для **Apple Silicon (M1 и новее)**
и **Intel x86_64**. Минимальная версия системы — **macOS 13 Ventura**
(требование Electron 44). Node.js, npm, Xcode и отдельный сервер на Mac
пользователя не нужны. Интерфейс, каталог и фотографии текстур включены
в приложение; без интернета используются системные шрифты вместо Google Fonts.

Сборка подписана локальной **ad-hoc** подписью для целостности приложения.
Это не подпись Developer ID; сборка не прошла нотариализацию Apple.
При переносе через браузер или мессенджер Gatekeeper может блокировать первый запуск.
После попытки запуска откройте **Системные настройки → Конфиденциальность
и безопасность → Всё равно открыть** и подтвердите запуск. Корпоративная
политика Mac может запрещать такое исключение.

Для распространения без этого предупреждения владельцу приложения нужны
Apple Developer Program, сертификат **Developer ID Application** и
нотариализация Apple. Секреты и сертификаты не хранятся в репозитории.

## Проекты

**Сохранить / Cmd+S** сохраняет проект локально в профиле приложения.
Несмотря на название `LocalSQLiteRepository`, текущая реализация использует
`localStorage`, а не SQLite. Каталог приложения хранится в
`~/Library/Application Support/Planko`; не удаляйте его при обновлении.

Для резервной копии и переноса проекта на другой Mac используйте
**Проекты → Экспорт проекта (.json)**, затем **Открыть (Импорт)**.
Копирование DMG или `.app` само по себе не переносит проекты.

## Сборка из исходников на Mac

Нужны Node.js **22.12+** (проверено на 24.22.1), npm и Apple Command Line Tools.
Полная установка Xcode не требуется. Если Command Line Tools ещё не установлены:

```sh
xcode-select --install
```

Из корня репозитория:

```sh
npm ci --registry=https://registry.npmjs.org
npm test
npm run test:types
npm run build:mac
```

Результат в `release/`:

- `Planko-1.0.0-universal.dmg` — установка перетаскиванием в Applications;
- `Planko-1.0.0-universal.zip` — архив с тем же приложением;
- `mac-universal/Planko.app` — готовое приложение.

Для сборок меньшего размера только под один процессор:

```sh
npm run build:mac:arm64
npm run build:mac:x64
```

Иконка `.icns` автоматически создаётся из существующей `public/planko.svg`.
Скрипты сборки явно выбирают ad-hoc подпись и отключают автоматический поиск
сертификатов. Для релиза с Developer ID эти настройки требуется заменить
и настроить нотариализацию в защищённой среде сборки.

## Изменения для macOS

- Добавлены универсальные DMG и ZIP, отдельные команды для arm64 и x64.
- Исправлен production preview: `NODE_ENV=production` загружает `dist/index.html`
  даже при запуске Electron без упаковки. Упакованное приложение всегда использует `dist`.
- Добавлены меню приложения, окна и редактирования, сочетания Cmd+C/V/X/A.
  Cmd+Z остаётся у обработчика истории проекта.
- Включён sandbox рендерера и восстановлена стандартная web security Electron.
- Обновлена транзитивная DOMPurify в lock-файле до исправленной версии.

## Проверка собранного пакета

Сборка проверена на macOS 26.6.2, Apple Silicon. Установленный из DMG пакет
также прошёл те же сценарии в режиме Intel x64 через Rosetta. Проверка на
физическом Intel Mac и на минимальной macOS 13 отдельно не выполнялась.

- Production-сборка и проверка TypeScript прошли; все **418 тестов** прошли.
- Упакованный `.app` запускается без сервера разработки и без интернета.
- Проверены создание проекта, Cmd+S, перезагрузка и повторное открытие.
- Проверены импорт проекта с шестью текстурами, 2D и 3D, четыре вида PDF
  и обратный экспорт проекта в JSON; ошибок рендерера и загрузки текстур нет.
- `npm audit --omit=dev` после обновления показывает **0** известных уязвимостей.
- Проверены подпись приложения, контрольная сумма DMG и CRC всех файлов ZIP.

Логи, снимки интерфейса и тестовые PDF находятся в `release/verification/`,
SHA-256 установщика и архива — в `release/SHA256SUMS.txt`.
